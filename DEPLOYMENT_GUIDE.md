## 📤 **GitHub Upload Steps**

### 1. **Initialize Git Repository**
```bash
git init
```

### 2. **Add All Files**
```bash
git add .
```

### 3. **Initial Commit**
```bash
git commit -m "Initial commit: Hospital Management System with responsive UI"
```

### 4. **Create GitHub Repository**
- Go to [GitHub.com](https://github.com)
- Click "New repository"
- Name: `hospital-management-system`
- Description: "A modern, responsive Hospital Management System built with Python and Tkinter"
- Make it Public or Private (your choice)
- **Don't** initialize with README (we already have one)

### 5. **Connect and Push**
```bash
git remote add origin https://github.com/yourusername/hospital-management-system.git
git branch -M main
git push -u origin main
```
